# TownOfNDev 0.1.0-beta.1

This is the first beta candidate for TownOfNDev.

## Baseline

`0.1.0-beta.1` is a version promotion of `0.1.0-alpha.12.0.4`.

There are **no gameplay or content changes** between those two source baselines.
The beta begins from the same tested implementation and asset-optimised source.

## Included role roster

- Tracer — Crewmate Investigative
- SUI — Crewmate Protective
- Condemner — Impostor Killing
- Fungi — Neutral Evil
- Troll — Neutral Evil
- Tank — Crewmate Protective
- Reverser — Impostor Power

- Eye Mask

- Laggy
- Menace

- Null

## Beta focus

The beta phase is for full regression testing, multiplayer validation, packaging,
repository publishing, release notes, and fixing issues found without expanding
the pre-beta feature scope unnecessarily.
